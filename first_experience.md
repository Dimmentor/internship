## Как начать работу с оркестратором

### 1. Перейдите по ссылке, чтобы открыть UI [Orchestrator](http://10.129.0.9:8081/)
- В верхней панели будет кнопка-дропдаун "Ещё" -> выберите "Новый workflow"
- Введите название графа, в соответствии с названием вашего проекта (например, code-review)
- В новом графе по-умолчанию будет один узел "LLM: генерация". Данный узел умеет вызывать только LLM, без MCP инструментов.
- Кликните на узел main: в правом меню (Инспектор) откроется настройка узла.
- Провайдер, модель, URL ollama будут заданы по-умолчанию, менять там ничего не нужно. 
- Нажмите на иконку "💾" сверху. Это запишет изменения в .json-файл.
- Теперь ваш граф с одним узлом готов принимать запросы(происходить это будет через `POST chat/completions`), но модель ещё не поднята.


### 2. Забронируйте виртуальную машину с LLM в [TimeNode](https://timenode.internal.wata-interns.pro/)
- Войдите по логину/паролю, которые вам отправил DevOps
- Запустите машину `compute-vm-ssd-io-llm` на нужное время (например, на 1 ч). Машина будет запущена примерно в течение 1 минуты. После запуска ollama будет запущена автоматически. Модель qwen3.6:27b уже скачана, но запущена не будет.


### 3. Холодный запуск модели
У нас есть готовый граф, поднята ollama, но не поднят qwen3.6:27b. 

- В UI, слева есть вкладка "Чат", нажмите на него
- В поле ввода сообщения введите простой запрос, например "Что такое LangGraph", оставьте галочку "stream" включенной.
- Нажмите на кнопку "Запуск". Первый запрос в ollama с вызовом модели qwen3.6:27b инициирует запуск модели. При этом модель будет запускаться около 2,5 минут, и только после этого будет обрабатываться ваш запрос.
- Через несколько минут вы получите ответ модели, он отобразится в чате. Так как мы ещё не создали thread, то история сообщений не будет сохранена. 
- Повторите тот же запрос, или любой другой. Ответ должен занять не более минуты.

### 4. Настройка узла main
- Установите любой желаемый системный промпт (роль агента)
- Уберите галочку `Thinking` при желании (модель будет быстрее отвечать, но менее умно)
- Нажмите на "Параметры", выставьте temperature 0, num_ctx 16384
- В меню `Чат`(слева), напротив `threads` нажмите на `+`, введите название истории сообщений - (например, dmitry_test_thread). Теперь история сообщений будет записываться в этот thread_id, но пока не будет сделано первого вызова - физически история не будет создана
- Запустите агента снова, дождитесь ответа
- Теперь можно сделать повторный запрос. Агент будет видеть прежнюю историю сообщений, что позволит вести диалог.
- Удалите ваш `thread_id`


### 5. Настройка ReAct агента и MCP-сервера
- Удалите узел main - выделите этот узел на канвасе, нажмите Delete.
- В левом меню, во вкладке "Узлы", нажмите на "Agent: ReAct". Узел будет добавлен на канвас. Соедините стрелки от `start` к агенту, и от агента к `end`.
- нажмите на канвас, чтобы сбросить выделение узла.
- Справа (в меню Инспектор), вы увидите каталог MCP серверов. Нам нужен только `mcp-file`.
- Поставьте галочку на инструментах "create_file", "get_file", "delete_file", затем сверху на кнопку "Подтянуть servers в policies". Это запишет адреса серверов в json-файл. Данное действие ограничит весь граф использованием только выбранных инструментов.
- Нажмите на иконку "💾" сверху, чтобы сохранить изменения.
- Нажмите на узел "Agent: ReAct" - доступны будут только выбранные инструменты для графа. Проставьте галочки.
- Снизу под инструментами, есть поле `MCP _meta (mcp-file)`, введите в него путь к вашей рабочей директории:
  ("sandbox_root": "/home/wata/sandbox/..."). 
- Вместо ... поставьте свою директорию, которая уже создана ("/home/wata/sandbox/aafanasiev", "/home/wata/sandbox/aantonov", "/home/wata/sandbox/svinokurov"). Сохраните изменения (💾). При этом, каждый вызов MCP сервера будет передан с этим параметром, который перехватит middleware MCP сервера и подменит рабочую директорию на переданную.
- Настройте агента (системный промпт, параметры и тд - как душа пожелает.) `Нативный tool calling (bind_tools)`, адреса ollama, модель - не трогать. Из параметров можно ограничиться `num_ctx=16384`.

- В меню "Чат" напишите "Создай файл TEST.md, запиши в него текст: 'Этот текст был записан с помощью ReAct-агента'".

### Explorer 
- Откройте вкладку `Explorer` в левом меню. В `Root` должно быть указано `/home/wata/sandbox`(если нет, то введите вручную и нажмите Enter)
- Как в IDE, перейдите в свою директорию. Если вы всё правильно сделали, то там должен быть созданный вами файл - TEST.md. Кликните на него 2 раза - откроется редактор Monaco, как в VSCode. 
- Убедитесь, что агент сделал то, что вы от него просили.
- Оставшееся время слота виртуальной машины с LLM, можете потратить с умом.
